Thử Nghiệm Tương Tác Thuộc Tính grid-row

Thay đổi giá trị grid-row của Ô 1 và quan sát sự dịch chuyển đường kẻ hàng cùng thuật toán sắp xếp tự động của Grid.

Nhập Giá Trị Tùy Chỉnh

Hiện vị trí các đường chỉ giới 1, 2, 3, 4 trên Grid.

Giải Thích Thuật Toán Định Vị:

Thuộc tính grid-row: 1 / 3; chỉ định Ô 1 bắt đầu tại đường kẻ hàng 1 (Grid Line 1) và kết thúc tại đường kẻ hàng 3 (Grid Line 3). Do đó Ô 1 sẽ kéo dài chiếm trọn 2 hàng (Hàng 1 và Hàng 2). Các ô còn lại (Ô 2 đến Ô 6) được Grid tự động đẩy sang các vị trí trống tiếp theo.

Trực Quan Khung Lưới (3 Cột x 3 Hàng) grid-row: 1 / 3;
Mã CSS Trực Tiếp (Live Inspector) 
/* Khung chứa 3x3 Grid */
.grid-container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    grid-template-rows: repeat(3, 100px);
    gap: 10px;
}

/* Cấu hình vị trí Ô 1 */
.item1 {
    grid-row: 1 / 3;
}

style.css 
/* Cấu hình khung chứa Grid 3 cột x 3 hàng */
.grid-container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    grid-template-rows: repeat(3, 100px);
    gap: 10px;
    background-color: #0f172a;
    padding: 15px;
    border-radius: 8px;
}

/* Kiểu dáng chung cho các ô */
.item {
    background-color: #1e293b;
    color: #ffffff;
    font-weight: bold;
    display: flex;
    align-items: center;
    justify-content: center;
    border-radius: 6px;
    border: 1px solid #334155;
}

/* Yêu cầu 2: Ô 1 chiếm từ đường kẻ hàng 1 đến 3 */
.item1 {
    background-color: #f59e0b;
    color: #0f172a;
    grid-row: 1 / 3; /* Thay bằng '2 / 4' cho yêu cầu 3 hoặc 'span 2' cho yêu cầu 4 */
}

Hướng Dẫn Nộp Bài GitHub & Kiểm Tra URL

Các bước đưa code lên Repository css-grid-row-practice và công cụ kiểm tra link nộp bài.

1 Tạo Thư Mục & Code Lập Trình

Tạo thư mục css-grid-row-practice trên máy tính, lưu 2 file index.html và style.css từ Tab Mã Nguồn.

2 Khởi Tạo Git Repository

Mở Terminal/Git Bash trong thư mục dự án và chạy các lệnh: 

git init
git add .
git commit -m "Complete CSS grid-row practice assignment"
3 Tạo Repo Trực Tuyến & Push Code

Trên GitHub, tạo mới repository đặt tên là css-grid-row-practice (chế độ Public), sau đó liên kết và push code: 

git remote add origin https://github.com/USERNAME/css-grid-row-practice.git
git branch -M main
git push -u origin main
4 Bật GitHub Pages (Tùy Chọn)

Vào Settings → Pages → Source: deploy from a branch (main / root) để xuất bản trang web live công khai.

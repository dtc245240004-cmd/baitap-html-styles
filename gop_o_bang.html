Chế độ HTML Cổ điển: Hiển thị đúng kết quả bảng mặc định trình duyệt khi tạo thuộc tính border="1". Chuyển sang CSS Hiện Đại để quan sát màu nổi bật của các ô được gộp hàng (rowspan) và gộp cột (colspan).

Sơ Đồ Phân Tích Ma Trận Tọa Độ Ô Gộp (4x3)

Minh họa cách trình duyệt tính toán tọa độ khi sử dụng rowspan và colspan

Hàng 0 (tr#0 - Headers) Cột 0 | Cột 1 | Cột 2

Giải thích cơ chế nhảy tọa độ trong cây DOM:

  • rowspan="2" ở ô Thứ Hai (Hàng 1, Cột 0): Ô này kéo dài xuống Hàng 2. Do đó ở Hàng 2, vị trí Cột 0 đã bị chiếm chỗ, mã HTML ở Hàng 2 chỉ cần khai báo 2 thẻ <td> (cho Môn học và Giáo viên) thay vì 3 thẻ!
  • colspan="2" ở ô Nghỉ học (Hàng 3, Cột 1): Ô này trải dài qua 2 cột (Cột 1 và Cột 2). Do đó Hàng 3 chỉ cần tổng cộng 2 thẻ <td> (Thứ Ba + Nghỉ học).

Bảng Tra Cứu Kiến Thức & Mẹo Tính Ô

Phân biệt thuộc tính rowspan vs colspan và quy tắc tính toán số ô

rowspan="N" Gộp Dọc / Gộp Hàng

Dùng khi muốn một ô mở rộng kéo dài xuống N hàng bên dưới trong cùng một cột.

<td rowspan="2">Thứ Hai</td>
Chú ý: Ở các hàng tiếp theo bên dưới, phải bỏ bớt 1 thẻ <td> tương ứng!
colspan="N" Gộp Ngang / Gộp Cột

Dùng khi muốn một ô mở rộng kéo dài qua N cột bên phải trong cùng một hàng.

<td colspan="2">Nghỉ học</td>
Công thức: Số ô <td> còn lại trong hàng = (Tổng số cột) - N + 1.

Chưa kiểm tra Repo
Các lệnh Git cần thực thi tại thư mục dự án:

# 1. Khởi tạo kho chứa Git local

git init

# 2. Thêm file index.html vào Stage

git add index.html

# 3. Tạo commit bài làm

git commit -m "Hoan thanh bai thuc hanh gop o trong bang HTML"

# 4. Liên kết tới GitHub Repo và đẩy code

git branch -M main

git remote add origin <LINK_GITHUB_REPO_CUA_BAN>

git push -u origin main
